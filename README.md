# Lohith Regalla Portfolio

Personal product-management portfolio built with Next.js 16, React 19, and Tailwind CSS 4.

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
npm audit
```

## Content

- Shared profile and contact information: `data/site.ts`
- Case-study content and document paths: `data/case-studies.ts`
- Downloadable case-study PDFs: `public/case-studies/`
- Full presentation assets: `public/case-studies/spotify/pages/` and `public/case-studies/netflix/pages/`
- Editable Spotify and Netflix presentation sources: `case-study-documents/`
- Case-study pages: `app/case-studies/`

The website distinguishes shipped work, product experience, and independent concepts. Keep those labels and evidence qualifications intact when updating content.
