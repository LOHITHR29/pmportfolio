# Case study documents

The Spotify and Netflix case-study PDFs are generated from the HTML presentations in this directory. The HTML remains the editable source of truth so future content corrections do not require editing raster images.

Both presentations use `shared.css`, a bundled Manrope font, fixed 1280 by 720 slide dimensions, and print styles that preserve selectable text in the exported PDFs.

The generated outputs replace these files:

- `public/case-studies/spotify-discovery.pdf`
- `public/case-studies/netflix-india-growth.pdf`
- `public/case-studies/spotify/pages/page-NN.png`
- `public/case-studies/netflix/pages/page-NN.png`
